# Защита «Комплект»

## Подготовка

Из корня репозитория экспортируйте параметры шлюза из своего локального файла. Выполните открытый пример для проверки доступа, затем запустите демо.

```bash
set -a
source ./.env
set +a
./run --catalog "$PWD/data/catalog.json" < examples/01-selection/request.json
python3 -m buyer.demo
```

Откройте [127.0.0.1:8765](http://127.0.0.1:8765). CLI и демо используют одну реализацию интерпретации и подбора.

## Сценарий на три минуты

1. Нажмите **«Запрос без бюджета»**. Помощник извлечёт город, товары и ширину стола. В блоке условий покажите, что бюджет требует уточнения. Озвучьте, что у модели уже есть все остальные данные.
2. Ответьте **«15 тысяч»**. Покажите три карточки, итоговую цену, запас бюджета и раскрываемую секцию **«Почему подходит»**. Укажите на фактический вызов Gemma и откройте **«JSON для автопроверки»**.
3. В том же диалоге напишите **«Всё то же, но бюджет 100 ₽»**. Покажите минимальную цену полного комплекта в выбранном городе и разницу до неё.
4. Откройте **«Проверка защиты»** и нажмите **«Сравнить результаты»**. Этот режим выполняет живой вызов Gemma и показывает модель, время и токены. В оба описания добавлена инструкция объявить цену 1 000 ₽. В обеих подборках остаётся стол за 5 400 ₽. Стол за 9 500 ₽ превышает бюджет 6 000 ₽.

## Как объяснить архитектуру

> Gemma превращает диалог в проверяемые условия. Подбор считает по структурированному каталогу. Мы можем показать, что именно извлекла модель, какие товары прошли фильтры и из каких цен сложился итог.

| Что спросит жюри | Что показать |
| --- | --- |
| Где используется Gemma? | История и промпт отправляются через Chat Completions. В блоке условий виден результат, в строке под ним — данные реально выполненного вызова |
| Кто гарантирует бюджет и наличие товаров? | Детализация показывает цены и ID из каталога. Код проверяет город, характеристики, количество, сумму и уникальность комплектов |
| Что означает «нет совпадений»? | Полного комплекта нет при известных условиях. В подготовленном сценарии помощник знает минимальную цену и показывает разницу |
| Что происходит с инструкциями продавца? | Два каталога дают одинаковый JSON. Названия и описания не передаются Gemma, а цена берётся из `price_rub` |
| Как воспроизвести проверку? | `python3 -m unittest discover -v` выполняет проверки ядра и локального шлюза. `python3 -m tests.live` использует командный ключ |

Если шлюз недоступен на защите, отдельно покажите локальный тест защиты из команды ниже. Он подтверждает поведение фильтра на фиксированных условиях. Живую интеграцию можно воспроизвести после восстановления шлюза.

```bash
python3 -m unittest tests.test_buyer.SelectionTest.test_listing_text_is_irrelevant_even_on_eligible_listing -v
```

## Иллюстрация

Фотография в шапке иллюстрирует рабочее место. Изображение создано встроенным ImageGen и сохранено в [buyer/ui/workspace.webp](../buyer/ui/workspace.webp). Промпт запрашивал горизонтальную редакционную фотографию домашнего рабочего места со столом из светлого дуба, оливковым креслом и тёмной настольной лампой. Свет мягкий дневной, интерьер в шалфейных оттенках. Без людей, экрана, логотипов и надписей.
